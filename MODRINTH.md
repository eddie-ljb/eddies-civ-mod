# Eddies Civ Mod

Turn your Minecraft world into a living civilization. Found towns, write a constitution, hold elections, run companies, go to court – and let villagers take part as citizens.

## Features
- **Towns:** town hall block, claimed territory, plots for sale or lease, protection, shops, bank and a server market with dynamic prices.
- **Villagers as citizens:** personality, mood, income, voting, parties, emigration, investing and working for companies.
- **Politics:** mayors, treasurers, planners and parliaments; plurality, runoff, Sainte-Laguë, D'Hondt, Hare-Niemeyer, majority, constituencies and mixed-member systems; person or list ballots, thresholds, term limits, compulsory voting.
- **Campaigns:** speeches, poster columns, promises, debates and a live election night with projections.
- **Law:** constitution and statute book blocks, laws by vote, federations (states, nations and custom levels).
- **Economy:** companies with production branches (forestry, sheep, farming, mining, fishing, ranching, brickworks, orchards), hiring, investing, a stock exchange with order book and dividends, newspapers that sway elections.
- **Justice:** criminal, civil and constitutional cases with judges, prosecutors, defence, witnesses, juries, evidence from your hand, verdicts, appeals and exile.
- **Daily life:** streets and addresses, contracts, mail, friends and trust, flags and anthems.
- **Website:** live map with rendered terrain, elections, market, stock exchange, press, state and justice pages, chat – built in, no plugin needed.
- German and English, all commands in both languages, in-game handbook, LuckPerms support via the Fabric permission API, automatic database backups.

## Install
One jar for server **and** client (the mod adds blocks). Requires Fabric Loader 0.19.5+, Fabric API 0.164.0+ and Java 25. Configuration: `config/eddies-civ-mod.properties`.
